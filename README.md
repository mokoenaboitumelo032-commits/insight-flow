# Insight Flow

Build a modern, responsive AI Workplace Productivity Assistant as a frontend-only SaaS web app. No backend, database, authentication, or external API integrations.

Create a clean professional dashboard with a deep teal/sea-green + bright cyan/turquoise colour palette, modern cards, rounded corners, subtle shadows, and responsive desktop/mobile layouts.

Include:

Dashboard – overview with quick-action cards for Email Generator, Research Assistant, and AI Chatbot.

Smart Email Generator – fields for recipient/context, email purpose, and tone: Formal, Friendly, or Persuasive. Generate polished, workplace-appropriate AI-style emails with editable output and Copy/Regenerate buttons.

AI Research Assistant – input for a topic or pasted article. Generate a structured summary, key insights, important points, and practical recommendations. Make the output editable and copyable.

AI Workplace Chatbot – conversational interface where users can enter workplace questions or tasks and receive helpful, context-aware AI-style responses. Include suggested prompts.

Sidebar navigation – Dashboard, Email Generator, Research Assistant, AI Chat, Settings.

Responsible AI notice – clearly state that AI-generated content should be reviewed for accuracy, context, confidentiality, and appropriateness before use.

Use realistic, context-aware AI-style responses rather than generic placeholder text. Since there is no backend/API, implement the AI interactions with frontend logic and predefined intelligent response patterns that adapt to the user's input.

Prioritise polished UX, accessibility, responsiveness, editable outputs, clear loading states, and a professional SaaS appearance. Keep the implementation lightweight and suitable for a free Lovable project.
