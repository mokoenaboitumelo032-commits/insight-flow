# AI Workplace Productivity Assistant

## Project Overview

The **AI Workplace Productivity Assistant** is a modern, responsive web application designed to help professionals complete common workplace tasks more efficiently using AI-powered features.

The application provides tools for generating professional emails, researching and summarising information, and interacting with an AI workplace chatbot. It is designed with a clean SaaS-style interface that is easy to navigate and use on both desktop and mobile devices.

This project is **frontend-only** and does not use a backend, database, authentication system, or external API.

## Features Implemented

### 📊 Dashboard
- Modern SaaS-style dashboard
- Quick access to all AI productivity tools
- Clean and responsive user interface
- Overview of available workplace productivity features

### ✉️ Smart Email Generator
- Generate professional workplace emails
- Enter the email purpose and context
- Select from different tones:
  - Formal
  - Friendly
  - Persuasive
- Editable AI-generated email output
- Copy generated emails
- Regenerate responses

### 🔎 AI Research Assistant
- Enter a research topic or paste an article
- Generate structured summaries
- Identify key points and insights
- Provide practical recommendations
- Editable generated content
- Copy research results

### 💬 AI Workplace Chatbot
- Interactive workplace AI assistant
- Users can enter workplace-related prompts
- Provides context-aware AI-style responses
- Suggested prompts for common workplace tasks
- Conversational chat interface

### 🎨 User Interface
- Modern SaaS dashboard design
- Sidebar navigation
- Responsive desktop and mobile layouts
- Deep teal/sea-green and bright cyan/turquoise colour palette
- Rounded cards and modern UI components
- Clear loading and interaction states
- Accessible and user-friendly design

### 🛡️ Responsible AI
- Includes a responsible AI disclaimer
- Reminds users to review AI-generated content
- Encourages users to verify accuracy and context
- Advises users not to enter confidential or sensitive workplace information

Responsible AI Disclaimer

AI-generated content may contain inaccurate, incomplete, or inappropriate information. Users should review and verify AI-generated emails, summaries, recommendations, and chatbot responses before using them in a professional environment.

Users should also avoid entering confidential, sensitive, or proprietary workplace information into the application.

Project Purpose

The purpose of this project is to demonstrate how AI-assisted productivity tools can be incorporated into a modern workplace application to support professionals with communication, research, and everyday workplace tasks.
